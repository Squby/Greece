# Ελληνικά — тренажёр греческого

Веб-приложение (PWA) для изучения греческого: слова и грамматика с уроков.
Весь контент хранится локально в браузере (IndexedDB), работает офлайн, ставится на телефон.

## Запуск

```bash
npm install
npm run dev      # режим разработки, http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # посмотреть собранную версию
```

## Разделы

- **📚 Уроки** — программа по порядку. Каждый урок = слова + правила + упражнения,
  у каждого урока свой прогресс.
- **🔁 Повторение** — слова из всех уроков, которые пора повторить (интервальный алгоритм
  SRS, в духе Anki/Duolingo), в трёх режимах:
  - *Карточки* — смотришь перевод, оцениваешь, как вспомнил
  - *По буквам* — пишешь греческое слово по переводу (есть экранная греческая клавиатура)
  - *На слух* — слушаешь произношение и записываешь
- **✏️ Редактор** — добавить свои слова/правила вручную.

## Как добавляются уроки

Контент уроков лежит в `src/content/lessons/` (по файлу на урок) и собирается
в `src/content/index.ts`. Рабочий процесс:

1. Присылаешь материалы урока (слова, правила, примеры).
2. Я формирую из них файл `src/content/lessons/lesson-NN.ts` и добавляю его в индекс.
3. Приложение при запуске синхронизирует контент в локальную базу.

Прогресс по словам (SRS) хранится отдельно и **не теряется** при обновлении уроков:
слова сопоставляются по ключу `lessonSlug::греческое_слово`.

## Технологии

- Vite + React + TypeScript
- Tailwind CSS v4
- React Router
- Dexie (IndexedDB) — локальное хранилище
- vite-plugin-pwa — установка на устройство + офлайн
- Web Speech API — озвучка греческого (`el-GR`)

## Озвучка

Произношение работает через синтез речи браузера. Греческий голос есть в Chrome / Edge
и в системах с установленным греческим TTS. Если голоса нет, режим «На слух» подскажет
открыть приложение в Chrome / Edge.

## Хранение данных

Все слова и грамматика лежат в IndexedDB этого браузера. При первом запуске добавляется
небольшой стартовый набор для примера — его можно отредактировать или удалить в «Редакторе».
